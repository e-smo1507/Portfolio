## ✨ Features

- 🎨 **Elegant Rose & Warm Cream Theme**: Dark luxury background (`#140a12`) paired with vibrant rose accents (`#fb7185`) and warm cream typography (`#f7f0e8`).
- 🕸️ **Interactive Constellation Canvas**: Custom HTML5 Canvas rendering an animated neural network / constellation particle graph that reacts to screen sizing.
- 📱 **Fully Responsive**: Fluid layout adapted for mobile, tablet, and desktop screens with a mobile hamburger navigation menu.
- 📜 **Scroll Reveal Animations**: Smooth scroll-triggered entry transitions powered by the native `IntersectionObserver` API.
- ♿ **Accessibility & Reduced Motion**: Automatically respects system `prefers-reduced-motion` settings.
- ⚡ **Zero External Dependencies**: Lightweight single-file structure with no npm build steps required — pure HTML5, Vanilla CSS, and JavaScript with Google Fonts.
